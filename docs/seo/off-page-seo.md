### 2.2 资源页外链

寻找已有的宠物资源列表页面，申请添加我们的链接。

**目标资源页类型**:
- 大学动物科学系的宠物资源页
- 动物收容所/救助组织的教育资源页
- 兽医诊所的推荐阅读页
- 宠物博客的工具/资源汇总页

"chinchilla" + "helpful links" + inurl:resources
"hedgehog care" + "link roundup"

### 2.4 断链建设（Broken Link Building）

#### 操作流程
1. 使用 Ahrefs "Broken Backlinks" 功能扫描竞品
2. 找到指向 404 页面的高质量外链
3. 创建或确认我们有对应的替代内容
4. 联系链接来源站点，建议替换为我们的 URL

#### 高概率目标
- 已关闭的宠物博客（hamsterific.com 等老站）
- 过期的宠物护理 PDF 链接
- 已删除的宠物论坛帖子
- 失效的兽医诊所资源页

## 三、社交媒体 SEO 协同

### 3.1 Pinterest（最高优先级）

Pinterest 是宠物内容领域的流量金矿，尤其适合我们的目标受众（18-35 岁女性）。

**策略**:
- 每篇文章创建 2-3 个 Pin 图（竖版 1000x1500px）
- Pin 标题包含主关键词
- Pin 描述使用 2-3 个 hashtag + 关键词
- 创建分类 Board: "Hamster Care Tips", "Chinchilla Guide", "Hedgehog Health"
- 信息图是 Pin 的最佳内容类型

**SEO 价值**:
- Pinterest Pin 可以被 Google 索引和排名
- Pinterest 是高权威域名，外链有 nofollow 但带来流量
- Pin 的病毒式传播可以间接产生自然外链

**发布频率**: 每天 5-10 个 Pin（使用 Tailwind 排期）

### 3.2 YouTube

**策略**:
- 为每个支柱页制作配套视频（5-10 分钟）
- "How to" 教程视频（设置笼子、给刺猬洗澡等）
- 视频描述中包含网站链接 + 文章链接
- 视频可嵌入博客文章（增加页面停留时间）

**优先视频主题**:
1. "How to Set Up the Perfect Hamster Cage" (高搜索量)
2. "What Do Hedgehogs Eat? Complete Food Guide" (高搜索量)
3. "Chinchilla Dust Bath: How to Do It Right" (视觉吸引力强)
4. "How to Hold a Hedgehog Without Getting Poked" (高点击率)

**SEO 价值**:
- YouTube 视频出现在 Google Video Carousel
- 视频描述中的链接（nofollow 但带流量）
- 嵌入博客增加用户参与指标

### 3.3 Instagram / TikTok

**策略**:
- 宠物短视频/Reels（15-60 秒）
- "Did You Know" 系列（宠物冷知识）
- Bio 中链接到网站（使用 Linktree 或类似工具）
- Instagram Stories 推广新文章

**SEO 价值（间接）**:
- 品牌知名度 → 品牌搜索量增加
- 社交信号（Google 否认直接排名因素，但有相关性）
- 粉丝转化为网站访客 → 用户行为信号

### 3.4 Reddit

**策略**:
- 活跃在 r/hamsters (300K+), r/chinchilla (60K+), r/Hedgehog (120K+), r/RATS (250K+)
- 提供有价值的回答（不要只发链接）
- 偶尔自然地分享我们的文章（当真正相关时）
- 参与讨论建立专家形象

**规则**:
- **不要** 垃圾式发链接（会被 ban）
- **要** 先提供有价值的回答，然后 "I wrote a detailed guide about this: [link]"
- 遵守每个 subreddit 的自我推广规则

## 五、外链质量控制

### 5.1 外链质量标准

| 指标 | 接受 | 拒绝 |
|------|------|------|
| Domain Rating | > 20 | < 10 |
| 相关性 | 宠物/动物/生活方式/健康 | 无关行业 |
| 流量 | 有实际有机流量 | 零流量的链接农场 |
| 链接类型 | Dofollow 编辑链接 | 全站页脚/侧边栏链接 |
| 上下文 | 在正文中自然嵌入 | 垂直列表中无上下文 |
| 语言 | 英文 | 非英文（除非高 DR） |

### 5.2 应避免的外链类型

```
NEVER:
- 付费链接（违反 Google 指南）
- PBN（私人博客网络）
- 链接交换计划（"你链接我，我链接你"）
- 自动化链接提交工具
- 低质量目录提交（除少数高质量行业目录）
- 评论区垃圾链接
- 论坛签名链接
```

### 5.3 外链监控与维护

**月度检查**:
1. Ahrefs "New Backlinks" — 发现新获取的链接
2. Ahrefs "Lost Backlinks" — 追踪丢失的链接并尝试恢复
3. 检查 toxic link ratio — 如超过 5% 需准备 disavow 文件
4. 追踪 referring domains 增长趋势

**Disavow 文件管理**:
- 仅在确认有害链接时使用
- 先尝试联系站长移除
- 联系无果后提交 disavow
- 每季度审查一次 disavow 文件

- `[brand name]`
- `[brand name] hamster`
- `[brand name] care guide`
