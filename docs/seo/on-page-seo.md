# 页面 SEO 指南

## 一、Title Tag 模板

### 公式与规则
- 长度：50-60 个字符（确保在 SERP 中完整显示）
- 主关键词靠前
- 每个页面 title 唯一
- 品牌名放在末尾，用 `|` 分隔

### 各页面类型 Title 模板

#### 支柱页（品类页）
```
{Pet Name} Care Guide: Everything You Need to Know | [Brand]
```
示例：
- `Hamster Care Guide: Everything You Need to Know | [Brand]`
- `Chinchilla Care Guide: Complete Owner's Manual | [Brand]`
- `Hedgehog Care: The Ultimate Beginner's Guide | [Brand]`
- `Fancy Rat Care Guide for New Owners | [Brand]`

#### 信息类博客文章
```
{Primary Keyword}: {Benefit/Hook} | [Brand]
```
示例：
- `What Do Hamsters Eat? Complete Diet & Food List | [Brand]`
- `Hamster Wet Tail: Causes, Symptoms & Treatment | [Brand]`
- `Why Does My Hamster Bite Me? 7 Reasons & Fixes | [Brand]`
- `Hedgehog Quilling: What It Is & How to Help | [Brand]`

#### 商业评测/对比类
```
{Number} Best {Product} in {Year} ({Qualifier}) | [Brand]
```
示例：
- `7 Best Hamster Cages in 2026 (Vet-Approved) | [Brand]`
- `Best Hedgehog Food in 2026: Top 5 Picks Reviewed | [Brand]`
- `Best Chinchilla Dust Bath Brands Compared | [Brand]`

#### "Can X Eat Y" 类
```
Can {Pet} Eat {Food}? Safe or Dangerous? | [Brand]
```
示例：
- `Can Hamsters Eat Bananas? Safe Fruits Guide | [Brand]`
- `Can Chinchillas Eat Apples? Vet-Checked Answer | [Brand]`

#### 对比类
```
{Pet A} vs {Pet B}: Which Is Right for You? | [Brand]
```
示例：
- `Hamster vs Gerbil: Which Pet Fits Your Lifestyle? | [Brand]`

#### 首页
```
[Brand Name] — Expert Care Guides for Exotic Small Pets
```

#### About 页
```
About [Brand Name] | Our Mission & Team
```

## 二、Meta Description 模板

### 规则
- 长度：150-160 个字符
- 包含主关键词（Google 会加粗匹配词）
- 包含行动号召（CTA）
- 传达页面价值（用户为什么要点击）
- 不要重复 title 内容

### 各页面类型模板

#### 信息类
```
Learn {topic} with our expert guide. Covers {subtopic 1}, {subtopic 2}, and {subtopic 3}. {CTA: Read our complete guide →}
```
示例：
```
Learn what hamsters eat with our vet-reviewed guide. Covers safe foods, portion sizes, and feeding schedules. Get the complete hamster diet list →
```

#### 商业类
```
Looking for the best {product}? We tested {number} options and ranked them by {criteria}. {CTA: See our top picks for {year} →}
```
示例：
```
Looking for the best hamster cage? We reviewed 7 top cages and ranked them by size, ventilation, and value. See our 2026 picks →
```

#### "Can X Eat Y" 类
```
Can {pet} eat {food}? {Yes/No}, but {key caveat}. Learn the safe amount, benefits, and risks. {CTA}
```
示例：
```
Can hamsters eat bananas? Yes, but only in small amounts. Learn the safe portion size, nutritional benefits, and potential risks for your hamster.
```

#### 支柱页
```
Everything you need to know about {pet} care — from housing and diet to health and behavior. Start your {pet} journey with confidence.
```

## 三、Heading 标签最佳实践

### 层级规则

```
H1: 每页唯一，包含主关键词，与 title 相关但不完全相同
  H2: 主要章节标题，覆盖子话题
    H3: 子章节标题
      H4: 细分内容（罕用）
```

### 具体规则

| 规则 | 说明 |
|------|------|
| H1 唯一 | 每页只有一个 H1，在页面最顶部 |
| H1 含关键词 | 主关键词出现在 H1 中 |
| H2 覆盖子话题 | 每个主要章节用 H2，覆盖 SERP 中的 PAA 问题 |
| H3 用于子分类 | H2 下的进一步细分 |
| 不跳级 | H1 → H2 → H3，不要 H1 → H3 |
| 描述性标题 | 用户扫一眼标题就能理解文章结构 |
| 含关键词变体 | H2/H3 中使用次要关键词和 LSI 词 |

### 示例：Hamster Diet 文章

```
H1: What Do Hamsters Eat? A Complete Diet Guide

H2: Hamster Nutritional Needs
  H3: Macronutrient Requirements
  H3: Vitamins and Minerals

H2: Best Commercial Hamster Foods
  H3: Pellet-Based Foods
  H3: Seed Mix Foods
  H3: Our Top 5 Picks

H2: Safe Fruits and Vegetables for Hamsters
  H3: Safe Fruits (With Portion Sizes)
  H3: Safe Vegetables
  H3: Herbs Your Hamster Can Eat

H2: Dangerous Foods to Avoid
  H3: Toxic Foods (Never Feed These)
  H3: Foods That Cause Digestive Issues

H2: Hamster Feeding Schedule
  H3: How Much to Feed
  H3: How Often to Feed
  H3: Fresh Water Requirements

H2: Special Diet Considerations
  H3: Baby Hamster Diet
  H3: Pregnant Hamster Diet
  H3: Senior Hamster Diet

H2: Frequently Asked Questions
  H3: Can hamsters eat bananas?
  H3: Can hamsters eat cheese?
  H3: How long can hamsters go without food?
```

## 四、图片 SEO

### 4.1 文件命名

```
Good: syrian-hamster-cage-setup.webp
Good: chinchilla-dust-bath-guide.webp
Good: hedgehog-eating-mealworms.webp

Bad: IMG_20260301.jpg
Bad: photo1.png
Bad: hamster.webp（太泛）
```

规则：
- 使用描述性英文短语
- 单词间用连字符分隔
- 包含相关关键词
- 小写字母

### 4.2 Alt Text 最佳实践

| 原则 | Good | Bad |
|------|------|-----|
| 描述性 | "Syrian hamster eating a small piece of banana" | "hamster" |
| 含关键词 | "Best hamster cage setup with 6 inches of paper bedding" | "cage" |
| 不堆砌 | "Hedgehog curled in a ball during quilling phase" | "hedgehog pet care hedgehog quilling hedgehog health" |
| 简洁 | 5-15 个单词 | 超过 125 个字符 |

### 4.3 图片格式与压缩

| 格式 | 用途 | 目标大小 |
|------|------|---------|
| WebP | 照片、截图 | < 100KB |
| AVIF | 照片（更高压缩比） | < 80KB |
| SVG | 图标、Logo、简单插图 | < 10KB |
| PNG | 透明背景图片（仅必要时） | < 150KB |

### 4.4 图片尺寸规范

| 位置 | 尺寸 | 说明 |
|------|------|------|
| Featured Image / OG Image | 1200 x 630px | 社交分享 + 文章 Hero |
| 文章正文图片 | 800 x 450px | 16:9 比例 |
| 信息图 | 800 x 2000px+ | 长图，适合 Pinterest |
| 产品图（Phase 2） | 800 x 800px | 1:1 方形 |

### 4.5 Lazy Loading

Next.js `<Image>` 组件默认 lazy loading，除非设置 `priority={true}`。

规则：
- 首屏图片（hero, 第一张图）：`priority={true}`
- 其他所有图片：默认 lazy loading
- 不要对 CSS 背景图使用 lazy loading（改用 next/image）

## 五、内链规则

### 5.1 锚文本类型分配

| 类型 | 占比 | 示例 |
|------|------|------|
| 精确匹配 | 20% | `[hamster care guide](/category/hamster)` |
| 部分匹配 | 40% | `[learn how to care for your hamster](/category/hamster)` |
| 品牌/通用 | 20% | `[our complete guide](/category/hamster)` |
| 长尾变体 | 20% | `[everything about hamster care for beginners](/category/hamster)` |

### 5.2 内链位置优先级

1. **正文上半部分**（最高价值）— 文章前 300 词内
2. **正文中部** — 相关段落中自然出现
3. **"Related Articles" 区块** — 文章末尾推荐
4. **面包屑导航** — 自动生成
5. **侧边栏/页脚** — 全站链接（价值较低）

### 5.3 内链实施规则

```
DO:
- 在首次提及相关话题时添加链接
- 使用描述性锚文本
- 链接到相关性最高的页面
- 确保支柱页和集群文章双向链接

DON'T:
- 不要在同一文章中重复链接到同一页面
- 不要使用 "click here"、"read more" 作为锚文本
- 不要在一个段落中放超过 2 条内链
- 不要链接到 noindex 页面
- 不要链接到带参数的 URL（用干净 URL）
```

## 六、内容格式化 SEO

### 6.1 列表优化（Featured Snippet 目标）

#### 有序列表（步骤/排行）
```markdown
H2: How to Tame Your Hamster (Step-by-Step)

1. **Let your hamster settle in** — Wait 3-5 days after bringing them home
2. **Talk to them softly** — Sit near the cage and speak gently for 10 min/day
3. **Offer treats by hand** — Place a treat on your open palm inside the cage
4. **Try gentle petting** — Once they climb on your hand, softly stroke their back
5. **Pick them up carefully** — Scoop with both hands, stay low to the ground
```

#### 无序列表（特征/清单）
```markdown
H2: Signs of a Healthy Hamster

- **Bright, clear eyes** with no discharge
- **Smooth, clean fur** without bald patches
- **Active and curious** during evening hours
- **Normal appetite** — eating and drinking regularly
- **Dry tail area** — wet tail is a medical emergency
```

### 6.2 表格优化

```markdown
H2: Hamster Species Comparison

| Feature | Syrian | Dwarf Campbell | Roborovski |
|---------|--------|----------------|------------|
| Size | 5-7 inches | 3-4 inches | 2-3 inches |
| Lifespan | 2-3 years | 1.5-2 years | 3-3.5 years |
| Social | Solitary only | Can be paired | Can be paired |
| Best for | Beginners | Experienced | Watching only |
| Cage size | 620+ sq in | 620+ sq in | 620+ sq in |
```

> 表格在 Google 搜索中可以直接被提取为 Featured Snippet。

### 6.3 FAQ 格式（PAA 优化）

```markdown
H2: Frequently Asked Questions

H3: How long do hamsters live?

Pet hamsters typically live **2-3 years** on average. Syrian hamsters
live 2-3 years, while Roborovski hamsters can live up to 3.5 years.
Proper diet, exercise, and veterinary care can maximize your
hamster's lifespan.

H3: Are hamsters good pets for kids?

Hamsters can be good pets for **children aged 10 and older** who can
handle them gently. Younger children should always be supervised.
Syrian hamsters are the best species for kids due to their larger
size and calmer temperament.
```

> 每个 FAQ 回答控制在 40-60 词，直接回答问题，适合被 Google 提取。

### 6.4 Key Takeaways / TL;DR

在文章开头（H1 之后）添加摘要框：

```markdown
**Key Takeaways:**
- Hamsters need a minimum cage size of 620 square inches
- Paper-based bedding (6+ inches deep) is safest
- A running wheel is essential — min 8" for Syrian, 6.5" for dwarf
- Avoid cedar and pine shavings (toxic fumes)
- Clean the cage fully every 2-4 weeks
```

### 6.5 "At a Glance" 信息框

用于支柱页和长文章顶部：

```markdown
**Hamster Care at a Glance**
| | |
|---|---|
| Lifespan | 2-3 years |
| Cage size | Min 620 sq inches |
| Diet | Pellets + fresh veggies + occasional treats |
| Temperature | 65-75°F (18-24°C) |
| Social needs | Solitary (Syrian) or paired (Dwarf) |
| Activity | Nocturnal/Crepuscular |
| Vet visits | Annual exotic vet checkup |
```

## 七、Featured Snippet 优化策略

### 7.1 三种 Snippet 类型与优化方法

| Snippet 类型 | 触发关键词 | 优化方法 |
|-------------|-----------|---------|
| 段落型 | "what is", "why", "how does" | H2 问题 + 紧跟 40-60 词回答 |
| 列表型 | "how to", "best", "top", "steps" | H2 + 有序/无序列表 |
| 表格型 | "vs", "comparison", "price", "size" | H2 + Markdown 表格 |

### 7.2 高价值 Snippet 目标关键词

| 关键词 | 当前 Snippet 持有者 | 我们的机会 |
|--------|-------------------|-----------|
| what do hamsters eat | thesprucepets.com | 更全面的食物清单表格 |
| hamster lifespan | google.com (knowledge panel) | 按品种对比表格 |
| hedgehog quilling | hedgehogworld.com | 更详细的步骤说明 |
| chinchilla dust bath | smallpetselect.com | 更中立的教育内容 |
| pet rat lifespan | petmd.com | 影响因素对比表 |

### 7.3 Snippet 优化模板

```markdown
H2: {问题关键词}?

{直接回答，40-60 词。第一句就给出明确答案。
后面补充关键细节。使用粗体标记核心数据。}

{更多详情、注意事项...}（这部分可能不被 snippet 选中，
但为读者提供完整信息）
```

## 八、页面加载体验优化

### 8.1 Above-the-fold 内容

用户进入页面后 **0.5 秒内** 应该看到：
1. 清晰的 H1 标题
2. 面包屑导航
3. 文章摘要/Key Takeaways
4. 作者信息和发布日期
5. Featured Image（已 preload）

### 8.2 避免影响阅读体验的元素

```
DON'T:
- 全屏弹窗/模态框（especially on mobile — Google 惩罚）
- 自动播放视频（影响 CWV）
- 过多广告（尤其在首屏 — 影响 Page Experience 信号）
- 大量社交分享按钮占用内容空间
- Cookie banner 遮挡大量内容

DO:
- 粘性目录导航（Table of Contents）
- 进度条（阅读进度指示）
- 相关文章推荐（文章末尾）
- 简洁的 Newsletter 订阅框（文章末尾，不弹窗）
```
