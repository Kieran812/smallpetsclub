# 关键词策略

## 一、关键词研究方法论

### 数据来源
- Google Keyword Planner（基础搜索量）
- Ahrefs / SEMrush（关键词难度、SERP 特征）
- Google Search Console（实际展现与点击）
- Google Trends（趋势与季节性）
- AnswerThePublic / AlsoAsked（问题类关键词）
- Reddit r/hamsters, r/chinchilla, r/Hedgehog, r/RATS（用户真实语言）

### 搜索意图分类
| 意图类型 | 定义 | 内容形式 | 占比目标 |
|----------|------|----------|----------|
| Informational | 用户想学习/了解 | 博客文章、指南、FAQ | 70% |
| Commercial Investigation | 用户在比较/评估 | 对比文章、评测、清单 | 15% |
| Transactional | 用户想购买 | 产品页、落地页（Phase 2） | 10% |
| Navigational | 用户找特定品牌/站点 | 品牌页面 | 5% |

## 四、"Can X Eat Y" 程序化关键词机会

这是异宠领域最大的长尾关键词金矿，每个问题 KD 极低（5-15），搜索量 500-6,600 不等，可以模板化批量生产。

### Hamster
- can hamsters eat bananas / strawberries / grapes / carrots / cheese / bread / watermelon / blueberries / cucumbers / lettuce / apples / celery / broccoli / tomatoes / peanuts

### Chinchilla
- can chinchillas eat apples / bananas / grapes / strawberries / carrots / hay / lettuce / blueberries / watermelon / raisins

### Hedgehog
- can hedgehogs eat cat food / bananas / apples / grapes / strawberries / mealworms / watermelon / eggs / chicken / carrots

### Fancy Rat
- can rats eat grapes / bananas / chocolate / cheese / strawberries / blueberries / bread / carrots / tomatoes / eggs

> **执行建议**: 为每种宠物创建一个 "Safe & Unsafe Foods" 支柱页，然后为高搜索量的个别食物创建独立文章，从支柱页链接过去。每篇 "can X eat Y" 文章 800-1200 词，包含明确的 Yes/No 答案（Featured Snippet 优化）、营养分析、喂食量建议、注意事项。

### 内链规则
1. 每篇集群文章必须链接回对应支柱页
2. 支柱页必须链接到所有集群文章
3. 同品类集群文章之间可交叉链接
4. 不同品类之间通过 "comparison" 文章桥接（如 "hamster vs chinchilla"）
5. 每篇文章至少 3 条内链，最多 10 条
